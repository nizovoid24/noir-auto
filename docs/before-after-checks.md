# BEFORE / AFTER — проверка

11 ноября 2026 года.

## Изображения

Оба PNG: 1448 × 1086, RGB, 4:3. Кадры визуально проверены: общий ракурс очень близкий, но контуры кузова и световые отражения слегка различаются. Это не идеально зарегистрированная пара; интерфейс содержит подпись об иллюстративном сравнении. CSS размещает изображения в одной области, без растяжения, обрезки и геометрической коррекции. Верхний кадр раскрывается clip-path. Все оригинальные PNG сохранены без изменений по SHA-256.

## Реализация

Начало — 50%. Слева ДО, справа ПОСЛЕ. Pointer Events и pointer capture для перетаскивания/клика; touch-action: pan-y pinch-zoom для вертикальной прокрутки и масштабирования. Range input сохраняет нативное управление клавиатурой, доступное название, aria-valuetext и видимый фокус. Изображения draggable=false, выделение текста внутри поля отключено. Разделитель перемещается без задержки/инерции; SectionReveal обеспечивает появление и reduced motion.
