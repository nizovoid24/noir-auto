# DETAILING CONFIGURATOR — проверка

11 ноября 2026 года.

## Реализовано

Секция после Before/After. Выбор автомобиля native radio, услуги native checkbox с подписями и fieldset/legend, доступный live output, сумма с короткой анимацией Motion. Сброс возвращает седан без услуг. Пустое состояние показывает «— ₽» и приглашает выбрать услуги. Никаких заявок, отправки данных или обещаний записи. Все цены демонстрационные; подпись об ознакомительном характере расчёта отображается постоянно.

Комплексный детейлинг — самостоятельная альтернатива, никогда не складывается с отдельными услугами. Выбор комплекса снимает остальные флажки; выбор отдельной услуги снимает комплекс. Правило описано перед выбором услуг.
