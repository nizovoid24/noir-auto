# NOIR AUTO — правила разработки

- Работать только в этой папке. Не менять Maison Éclat, родительский KALLISTO и пользовательские Skills.
- Демонстрационный сайт студии детейлинга для портфолио KALLISTO IT-AGENCY. Явно обозначать демонстрационный статус.
- Стек: React, Vite, TypeScript, Motion for React (`motion/react`), обычный CSS с переменными.
- Не добавлять платные API, тяжёлые 3D-библиотеки и зависимости без необходимости.
- Цвета: Obsidian Black #09090B; Crimson Red #C91620; Steel Silver #B7B7BD; Graphite #27272C.
- Rajdhani — крупные английские заголовки. Manrope — русский текст и интерфейс. Шрифты локальные, с лицензиями.
- Не выдумывать адреса, отзывы, сертификаты и факты о действующем бизнесе. В конфигураторе использовать только условные цены и коэффициенты из задания; явно обозначать демонстрационный статус. Не создавать рабочую запись без отдельного задания.
- Реализованы Hero, PHILOSOPHY, SERVICES, BEFORE / AFTER, PROCESS, DETAILING CONFIGURATOR, FINAL CTA и FOOTER. Сохранять композицию и анимации существующих секций. Другие секции и рабочие формы не создавать без отдельного задания.
- Оригиналы `public/images` не изменять и не удалять. Для будущей оптимизации создавать отдельные производные файлы.
- Сохранять семантический HTML, видимый focus, контраст текста и поддержку prefers-reduced-motion. Проверять от 320px.
- Компоненты: src/components; секции: src/sections; CSS: src/styles. Не создавать пустые абстракции ради структуры.
- Использовать установленные ui-ux-pro-max и impeccable с учётом конкретного этапа; явный бриф пользователя приоритетнее общих рекомендаций.
- npm-кэш направлять в `.cache/npm`, временные проверки — в `.cache/qa`. Не использовать глобальную установку пакетов.
- Перед сдачей выполнить `npm run build`; при изменениях интерфейса проверить адаптивность в браузере. Сообщать о непроверенных аспектах.
